# NS EXIM Premium Wholesale Website

Next.js + Tailwind + Framer Motion + Supabase architecture for a luxury leather belt wholesale brand.

## Included
- Multi-page user experience (home, products, product detail, about, contact, inquiry cart)
- Admin dashboard routes (login, products, categories, inquiries)
- Structured content folders under `/content`
- Supabase schema for products, categories, images, and inquiries

## Setup
1. `npm install`
2. Copy `.env.example` to `.env.local`
3. Add Supabase project credentials
4. `npm run dev`

## Notes
- WhatsApp inquiry link is integrated with prefilled product messages.
- Payment gateway is intentionally omitted per requirement.
